# Security policy

## Reporting a vulnerability

Please report security issues privately through GitHub's
[private vulnerability reporting](../../security/advisories/new) rather than a
public issue or pull request. Include what you found, how to reproduce it, and
the affected component (`bridge`, `worker`, `sync`, `reports`, `harness`).

## Contributions

Pull requests from forks are welcome but are never merged automatically: CI on
a fork's PR runs without any secrets and needs maintainer approval, and
bridge's automation ignores PRs that do not come from this repository's own
branches.
